# 把话讲明白 · clear-explanations

**简体中文** | [English](README.en.md)

**让 AI 把话说清楚，让你更容易理解。**

你有没有遇到过：AI 写了很长一段，你看完还是不知道重点；追问“能不能讲明白一点”，它又把同样的话说了一遍。

这个 Skill 就是为这样的时刻做的。它会根据你在讨论什么、需要怎样的回答，选择合适的讲法：简单问题直接答，复杂任务先理清思路，专业分析保持准确和严谨。你可以一开始就用，也可以在没听懂时让它重新解释。

## 比如，你想做一份销售分析

**你问：“老板让我分析这个月的销售情况，我应该先看什么？”**

你可能会得到这样的回答：

> 建议从销售规模、增长趋势、产品结构、客户分层和渠道表现等维度展开，结合同比、环比识别异常，进一步下钻分析。

方向不少，但第一步做什么、为什么这样做，还不够明确。可以这样组织：

> **分析目标：识别本月销售变动的主要来源，并判断其驱动因素。**
>
> 分析按四个层次展开：
>
> 1. **总体表现：** 对比本月与上月销售额，确认变动幅度；若存在明显季节性，再结合去年同月数据判断趋势。
> 2. **结构贡献：** 按产品、区域或渠道拆分，识别对整体增减贡献最大的部分，确定后续分析重点。
> 3. **驱动因素：** 针对主要变动来源，从销量、实际成交价格及产品组合等方面解释变化，再结合促销、供货等业务信息核实原因。
> 4. **结论与建议：** 汇总主要发现，区分已确认原因与待验证判断，提出相应措施或进一步核查事项。
>
> 若分析目标是解释“销售增长但利润下降”，还需纳入成本与利润，调整分析重点。

这里先明确目标，再交代分析路径。专业表达可以保留，读者也能看出各部分怎样服务于同一个问题。

*这是为说明讲法编写的例子，不是真实对话记录，也不是每次回答都要套用的模板。*

## 什么时候可以用

- 学习新概念，希望解释能从自己熟悉的内容讲起。
- 阅读分析或方案，希望先抓住重点，再理解依据和细节。
- 比较不同选择，想知道差异在哪里、各自适合什么情况。
- 只卡在某一句或某一步，希望补充这一处，不用从头重讲。

讲明白的方式不止一种。日常交流可以自然简短，专业讨论可以严谨精练；需要全貌时给框架，需要一个解释时就解释这一处。你指定的篇幅、风格和格式优先。

## 下载与使用

在仓库页面选择 **Code → Download ZIP**，解压后将文件夹命名为 `clear-explanations`。也可以只把 [SKILL.md](SKILL.md) 保存到同名文件夹里。

**在 Codex 中：** 按[当前官方说明](https://learn.chatgpt.com/docs/build-skills)，用户级安装路径为：

```text
~/.agents/skills/clear-explanations/SKILL.md
```

仅供某个项目使用时，放到该项目的 `.agents/skills/clear-explanations/` 下。已有同名 Skill 时，先比较或备份。不同版本的目录约定可能不同，请以所用工具的说明为准。

安装后试试：

```text
$clear-explanations 请解释这个方案，保留专业表达，先给整体思路。
```

也可以接着已有对话说：

```text
$clear-explanations 第二步我没理解，请只解释这一处。
```

如果安装后没有出现，请重启 Codex。执行指引目前为中文，无脚本，不需要额外 API 密钥。其他 AI 工具请按各自方式安装；也可以尝试把 `SKILL.md` 正文作为对话指引使用。

## 为什么做这个

我在和 AI 一起写代码、做产品时，经常遇到这种情况：它解释了很多，我却还是不知道为什么要这么做，或者接下来该干什么。有时我只是卡在其中一步，它却又从头讲了一遍。

于是，我把自己希望它怎样回答、没听懂时怎样重新解释，整理成了这个 Skill。它会随着使用中发现的问题持续改进，也欢迎你通过 Issues 告诉我：哪里没讲清楚，或者怎样讲会更好理解。

讲得明白，内容也可能有错；重要的事实和结论仍需核实。
